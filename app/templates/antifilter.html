💡 سازوکار ضدفیلتر چگونه است؟

شما می‌توانید برای هر پورت پروکسی، چندین آدرس (آی‌پی یا دامنه کمکی) به عنوان Endpoint اضافه کنید. پنل به طور منظم سلامت تمام این مسیرها را می‌سنجد و آدرس فعال و سالم را در لینک اصلی کاربران قرار می‌دهد.

• با ست کردن «دامنه مدیریت‌شده» و اتصال حساب کلودفلر، در صورت بروز فیلترینگ، رکورد DNS دامنه به صورت خودکار به آی‌پی سالم بعدی سوئیچ خواهد شد و اتصال کاربران بدون تغییر لینک برقرار می‌ماند.
• توجه: از آنجا که سیستم فیلترینگ ایران از خارج کشور قابل تشخیص خودکار نیست، چرخش خودکار سیستم فقط بر روی قطعی‌های سرور (Down شدن) عمل می‌کند. برای سنجش فیلترینگ از داخل ایران از دکمه «تست از ایران» استفاده کنید.

📘 راهنمای فعال‌سازی Cloudflare Spectrum

(برای مطالعه راهنما کلیک کنید)
💡 نکته فنی بسیار مهم: سرویس Spectrum برای پورت‌های TCP دلخواه (که پروتکل MTProto روی آن کار می‌کند) فقط در پلن Enterprise کلودفلر ارائه می‌شود. در صورتی که این پلن را ندارید، از ترکیب Endpoint + دامنه مدیریت‌شده + فِیل‌اوور DNS به صورت کاملاً رایگان استفاده کنید که نتیجه مشابهی دارد.
مراحل فعال‌سازی Spectrum:
  1. در پنل کلودفلر به بخش My Profile → API Tokens → Create Token بروید و یک توکن با دسترسی‌های ویرایش Zone : Spectrum : Edit و Zone : DNS : Edit ایجاد کنید.
  2. کد Zone ID را از صفحه Overview دامنه بردارید.
  3. اطلاعات فوق و آی‌پی عمومی سرور را در بخش «تنظیمات» پنل ذخیره کنید.
  4. هنگام ساخت پروکسی، نوع اتصال را کلودفلر انتخاب کرده و مشخصات Edge Domain را وارد کنید.
