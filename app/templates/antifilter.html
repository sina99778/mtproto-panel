سازوکار ضدفیلتر چگونه کار می‌کند؟

برای هر پورت پروکسی می‌توانید چندین آدرس (آی‌پی یا دامنهٔ کمکی) به عنوان Endpoint اضافه کنید. پنل به طور منظم سلامت تمام این مسیرها را می‌سنجد و آدرس فعال و سالم را در لینک اصلی کاربران قرار می‌دهد.

  • با ست کردن «دامنهٔ مدیریت‌شده» و اتصال حساب Cloudflare، در صورت قطعی سرور رکورد DNS دامنه به‌صورت خودکار به آی‌پی سالم بعدی سوئیچ می‌شود و اتصال کاربران بدون تغییر لینک برقرار می‌ماند.
  • توجه: از آنجا که سیستم فیلترینگ ایران از خارج کشور قابل تشخیص خودکار نیست، چرخش خودکار فقط بر روی Endpointهای قطع‌شده (DOWN) عمل می‌کند. برای سنجش فیلترینگ از داخل ایران از دکمهٔ «تست از ایران» استفاده کنید.

مراحل فعال‌سازی Spectrum

  1. در پنل کلودفلر به My Profile → API Tokens → Create Token بروید و توکنی با دسترسی‌های Zone : Spectrum : Edit و Zone : DNS : Edit بسازید.
  2. کد Zone ID را از صفحهٔ Overview دامنه بردارید.
  3. اطلاعات فوق و آی‌پی عمومی سرور را در بخش «تنظیمات» ذخیره کنید.
  4. هنگام ساخت پروکسی، نوع اتصال را کلودفلر انتخاب کرده و مشخصات Edge Domain را وارد کنید.
